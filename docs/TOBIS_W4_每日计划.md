## 模考的形式

- **结构**：Part 1（2 段对话）→ Part 2（短句，英→日、日→英各约 10 题，每个方向最后 3 题连续）→ Part 3（演讲，英→日、日→英各 1 段），总共约 60 分钟。
  题数参考 CAIS 官方样题的形式，**不使用官方题目**。正式考试的具体题数以 CAIS 的考试说明为准。
- **模考视频不出答案卡**：每题只有「听 → 提示音 → 倒计时」，和真实考试一样一口气做完。
- **答案另外给**：同一套题目生成一份「答案对照表」（参考译文 + 要点，由 `scripts/make_appendix.py` 从 JSON 生成），模考结束后再看。
- **录音条件尽量接近考试**：戴耳机、对着麦克风、中途不暂停、不重来。
