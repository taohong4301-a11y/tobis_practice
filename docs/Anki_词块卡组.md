# TOBIS 词块 Anki 卡组（2026-11-14 建）

> 目的：**在视频里听到之前，先把词块和搭配记住**。视频只用来练反应；词块本身靠 Anki 每天复习。
> 目标：**每天 50 个新词块 × 两个方向 = 每天 100 张新卡，11/14 → 12/1 学完 894 个词块（1,788 张卡）**。

## 1. 卡组里有什么

导入文件：`output/anki/TOBIS_chunks.apkg`（重新生成：`python scripts/make_anki.py`）。
词块表：`anki/chunks.tsv`（视频素材）、`anki/topics.tsv`（话题扩充），可以直接编辑后重新生成。

| 子卡组 | 来源 | 词块 |
| --- | --- | --- |
| `TOBIS 词块::1 已有素材 A·B` | 数字单位 7 + A 套 Part 2（134）+ B 套 Part 1 对话（115）+ 会议定型表現（20） | 276 |
| `TOBIS 词块::2 扩充 Vol.3 C·D` | 出力テンプレート（30）+ C 套 Part 2（92）+ D 套 Part 1 对话（74）+ 数字 3（10）+ Part 3 入门（8） | 214 |
| `TOBIS 词块::3 话题扩充` | 10 个 TOBIS 常考话题各约 40 个：業績・決算 / 金融市場 / 人事・労働 / 供給網・製造 / ESG・エネルギー / 会議・交渉 / マクロ・政策 / IT・データ / M&A・ガバナンス / 消費・観光・社会 | 404 |
| 合计 | | **894** |

- **收的是词块，不是单词**：例如「政策金利を据え置く」「業績予想を上方修正する」「条件を詰める」——口译时整块拿出来用。
- 每个词块有两种卡：
  - 卡 1「聞く→意味」：正面是日语，并自动播放语音 → 用英语说出意思（练「听到就懂」）。
  - 卡 2「英→日」：正面是英语（视频素材的词块还附上原题的英文句子）→ **出声说出日语**，再翻面（练「张口就有」）。
- 背面有：平假名读音、日语语音（Kokoro jf_alpha）、出处；卡组 1・2 还有原题的日英例句，词块在例句里标粗。
- 读音全部用 pyopenjtalk 对过。TTS 读错的 6 条（生成AI、50対50、粗利益率、ESG投資、お手数、著作権）语音改读平假名，保证读音正确。
- **没有收模考 E/F/G 的词**：模考前先学了，模考就不准了。

## 2. 两个方向都学（2026-11-14 决定）：复习量会到每天 250–300 张

| 日期 | 新卡 | 复习（估算） |
| --- | --- | --- |
| 11/20 | 100 | 约 165 |
| 11/25 | 100 | 约 225 |
| 12/1 | 88 | 约 285（峰值约 295，在 11/30 前后） |
| 12/8 | 0 | 约 135 |
| 12/12 | 0 | 约 120 |

（粗略模拟：FSRS、期望记忆率 0.90、第一次见到新卡时约 30% 想不起来。实际数字会因人而异。）

- **最大复习数一定要调高到 300**。如果还设成 150，从 11/22 左右开始每天都会剩下复习做不完，越积越多，记住的词也会忘掉。
- 时间：11 月下旬每天大约 **80–100 分钟**。建议拆成两三段（早上、通勤、睡前），不要占用 2 小时的核心口译时间。
- 如果哪天做不完：**先把复习做完，新卡少学一点**（当天在 Anki 里把新卡上限调低就行），不要反过来。新卡晚学一两天，总进度只会推后几天，影响不大。
- 后面想减负的话，可以把「聞く→意味」卡暂停：Anki「浏览 / Browse」→ 搜索 `deck:"TOBIS 词块" card:1` → 全选 → 「暂停 / Suspend」。这样复习量大约减半，以后随时可以取消暂停。

## 3. Anki 设置（导入后做一次）

在父卡组 `TOBIS 词块` 的选项里：

| 设置 | 值 | 原因 |
| --- | --- | --- |
| 新卡片 / New cards per day | **100** | 50 个词块 × 两个方向 |
| 最大复习数 / Maximum reviews per day | **300** | 见第 2 节；设成 150 会积压 |
| 埋藏新卡的兄弟卡 / Bury new siblings | **关闭**（默认就是关闭） | 打开的话，同一个词块的两张卡会分到两天学，进度就变成每天 100 个词块的单向卡，和上面的时间表对不上 |
| **新卡片收集顺序 / New card gather order** | **位置升序 / Ascending position** | 不改的话，Anki 会按卡组名的顺序一个卡组一个卡组地学，就不是下面这张按视频排好的时间表了 |
| **FSRS** | **开启**，期望记忆率 0.90 | 用旧的 SM-2 算法，复习量会多 40% 左右 |

## 5. 怎么用（每天）

1. **英→日卡一定要出声说**，说完再翻面，然后跟着语音说一遍。只在心里想不算。
2. 打分要诚实：说不出来，或者说错一个助词，都按「重来 / Again」。
3. 可以拆开做（比如通勤时做一部分），不要占用每天 2 小时里的核心口译时间。
4. 做视频练习时卡住的新表达，加进 `anki/chunks.tsv` 或 `anki/topics.tsv`，重新运行 `python scripts/make_anki.py`，再导入一次：已有的卡会更新，学习进度不会丢。
