# TOBIS 词块 Anki 卡组（2026-11-14 建）

> 目的：**在视频里听到之前，先把词块和搭配记住**。视频只用来练反应；词块本身靠 Anki 每天复习。

## 1. 卡组里有什么

导入文件：`output/anki/TOBIS_chunks.apkg`（重新生成：`python scripts/make_anki.py`）。词块的原始表在 `anki/chunks.tsv`，可以直接编辑后重新生成。

| 子卡组 | 来源 | 词块 | 卡片 |
| --- | --- | --- | --- |
| `TOBIS 词块::1 已有素材 A·B` | 数字单位 7 + A 套 Part 2（134）+ B 套 Part 1 对话（115）+ 会议定型表現（20） | 276 | 552 |
| `TOBIS 词块::2 扩充 Vol.3 C·D` | 出力テンプレート（30）+ C 套 Part 2（92）+ D 套 Part 1 对话（74）+ 数字 3（10）+ Part 3 入门（8） | 214 | 428 |
| 合计 | | **490** | **980** |

- **收的是词块，不是单词**：例如「政策金利を据え置く」「方針を固める」「前年比〜%増」——口译时整块拿出来用。
- **每个词块两张卡（双向）**：
  - 卡 1「聞く→意味」：正面是日语，并自动播放语音 → 用英语说出意思。练「听到就懂」（日→英题）。
  - 卡 2「英→日」：正面是英语和这一题的英文原句 → **出声说出日语**，再翻面。练「张口就有」（英→日题）。
- 背面有：平假名读音、日语语音（Kokoro jf_alpha）、出自哪一题、那一题的日英例句（词块在例句里标粗）。
- 读音已经用 pyopenjtalk 逐条对过；TTS 和标注不一致的两条（生成AI、50対50）语音改读平假名，保证读音正确。
- **没有收模考 E/F/G 的词**：模考前先学了，模考就不准了。

## 2. 每天 50 张能不能做到？

- 「每天 50」按 **卡片** 算 = 每天 **25 个词块 × 双向**。
- 只用已有素材（A·B）：552 张 ÷ 50 = 11 天，到 11/24 就学完了，**撑不到 12/1**。
- 所以用 Vol.3（C·D·出力型，已经写好，题材正是商务口译对话）补上：合计 980 张 ÷ 50 = **20 天，11/14 → 12/3**。
  - 一定要 12/1 学完：新卡改成每天 **55**。
- 结论：**不需要再另外编「随机话题词」**。Vol.3 的题材本来就覆盖 TOBIS 的范围（业绩、金融政策、人事、供应链、ESG、会议用语），而且之后的视频里会再听到这些词。

## 3. Anki 设置（导入后做一次）

在父卡组 `TOBIS 词块` 的选项里：

| 设置 | 值 | 原因 |
| --- | --- | --- |
| 新卡片 / New cards per day | **50**（想 12/1 学完就 55） | |
| 最大复习数 / Maximum reviews per day | **150** | 你定的复习上限 |
| **新卡片收集顺序 / New card gather order** | **位置升序 / Ascending position** | 不改的话，Anki 会先学完卡组 1 再学卡组 2，就不是下面这张按视频排好的时间表了 |
| **FSRS** | **开启**，期望记忆率 0.90 | 见下面的复习量估算 |

### 复习量估算（粗略模拟）

| 算法 | 11/25–12/3 平均每天复习 | 峰值 | 12/10 左右 |
| --- | --- | --- | --- |
| FSRS（推荐） | 约 120 | 约 140（12/4） | 约 60 |
| 旧算法 SM-2 | 约 175 | 约 195 | 约 85 |

- 开启 FSRS 时，复习量能控制在 150 以内；用旧算法会超过 150，复习就会积压。
- **时间**：50 张新卡加 120 张复习，每天大约 30–40 分钟（英→日卡要出声说，比较慢）。可以拆开做，比如通勤时做一部分。不要占用每天 2 小时里的核心口译时间。
- 12/4 以后不再加新卡，复习量逐渐下降，正好留出时间准备 12/13 的考试。

## 5. 怎么用（每天）

1. **卡 2（英→日）一定要出声说**，说完再翻面，然后跟着语音说一遍。只在心里想不算。
2. 打分要诚实：说不出来，或者说错一个助词，都按「重来 / Again」。
3. 做视频练习时卡住的新表达，写进 `anki/chunks.tsv`（格式见文件开头），重新运行 `python scripts/make_anki.py`，再导入一次：已有的卡会更新，学习进度不会丢。
4. 之后每周的新素材（错题合集等）也用同样的方法加进去。
