## 考试当天策略卡（12/6 写好，自己补充）

1. **数字最优先**：一听到就写，当场换算（billion → 億，万 → thousand×10）。
2. **不停下来**：倒计时开始就开口；没听懂的部分省掉，说出主语 + 方向 + 数字的完整句子。
3. **Part 1**：听到英语出日语，听到日语出英语；当社 = we，御社 = your company。
4. **Part 2**：每个方向最后 3 题是同一话题，前一题的内容可以帮你理解下一题。
5. **Part 3**：只说主题、2–3 个要点、数字。表现不影响 3 級，不要慌。
6. **一题没做好就忘掉它**，下一题重新开始。
